# Hera-Flux
<P>
This project is the brain child of Dan Diamond. 
<br />
The Hera-Flux core is designed to be a home/hobby manufacturing fabrication lab, built around an extruded aluminum rail frame of 609.6 mm³.
<br />
Using a range of 2020-80 series rails for rigidity & component support of all sub components.
Each frame is broken down into it's prime function. Print, CNC, Form, Fab, DEL(Desktop Electronics Lab)(PCB & Electronics production).
<br />
Each category borrowed from the Open Source Hardware community allowing this compilation of projects to help others bring a vision or dream to life!
